# Infinity-Pit-Probability-Calculator-
A Calculator for the Infinity Pit Probability.

When studying Quantum Mechanics, the students are introduced to the Infinity Pit problem. When dealing with the consequences of it, they are intended to calculate a huge equation for the probability of the location of some particle in the pit. Sometimes, calculate the whole equation can be a hardwork. In order to make the process faster, I built a Calculator for that probability. I hope it to be usefull.
